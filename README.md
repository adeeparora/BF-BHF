# BF / BHF document archive

Bajaj Finance and Bajaj Housing Finance annual reports, investor presentations and conference call transcripts.

Documents are organised under `BF/` and `BHF/`, each with `annual-reports/`, `presentations/` and `concall-transcripts/`.

See [document index](catalog/INDEX.md), [download manifest](catalog/manifest.json) and [collection runs](https://github.com/adeeparora/BF-BHF/actions/workflows/collect-documents.yml). The first collection populates these catalogs. Failed sources/downloads are recorded, never counted as archived documents.

Sources: issuer investor-relations pages and public document links indexed by Screener (including BSE and NSE filings). No Screener account credentials are stored. The collection runs on this initial setup push and can be rerun manually; no recurring schedule is enabled.
